Class 1 — One-Pager: Mythos & Cyber Security

UPSC GS-3 Internal Security (cyber) + Prelims — Satvik Bhan CA, lecture of 02-07-2026 — last-minute revision sheet
Full notes: notes.html · Static GK: cyber-security-static.html

1. What is Mythos

  • Frontier AI model by Anthropic (~Apr 2026): strong at vulnerability detection, cyber-security reasoning, software analysis.
  • Limited-access cohort: Project Glasswing (~40 firms). Rival capability: Qihoo 360 (China).
  • Not built for cyber — general model that turned cyber-relevant.
  • Lecturer's figure: 10,000+ major vulnerabilities in a month; a ~27-year-old bug.
Keywords: frontier AI model · zero-day · patch · threat actors · defender overload · supply-chain security · legacy software · AI cyber arms race.
Software has hidden bug→Mythos finds it→0 days to fix = zero-day
Defender first → PATCHvsAttacker first → EXPLOIT

2. Mythos vs other LLMs

  • Others: assist coding, debug (give patch), write scripts; limited autonomy (repeated prompts); detect some bugs, not at scale.
  • Mythos: finds zero-days at scale, autonomous; chains many low-severity bugs → one destructive attack.
  • UK AI Safety Institute: can autonomously attack small, weakly defended enterprise systems; engineers without formal security training can exploit fast → low entry barrier.
Shift: State-led cyber security → ransomware groups / non-state actors (box title: "Shift in cyber security post-Anthropic").

3. Broad & cyber implications

  • Dual-use dilemma: defence (states) + offence (non-state). Right question = who gets access · what safeguards · what accountability.
  • Machine-speed discovery → defender overload (find faster than verify/prioritise/patch).
  • Supply-chain security: shared libraries, open source, cloud, third-party vendors (e.g. Zoho, MeghRaj).
  • Attacks more scalable, automated, accessible; legacy interconnected infra hard to patch → systemic risk.
  • More dependence on foreign AI for detection/patching.

4. Sectoral impact

  • Critical infrastructure: grid (Spain, Netherlands cases), ports, rail (IRCTC), airports (IndiGo), hospitals, telecom, highways; SCADA in wind turbines (foreign-made).
  • BFSI: digital robbery, payment gateways/aggregators. Why prone: shared digital infra + structural issue = complexity (CBS) + legacy zero-days that evaded audits.
  • DPI: Aadhaar (~134 cr holders), CoWIN, DigiYatra, DigiLocker, PFMS, Sanchar Saathi, Chakshu; UPI-based finance. Stack = cloud + open source + shared libraries.
  • National security: defence systems · strategic communication · intelligence platforms · critical infrastructure.
  • Citizens: identity theft, fraud, phishing, impersonation, deepfakes.
  • Sovereignty: beyond borders (LAC, drone smuggling, FICN) → data sovereignty; India depends on foreign AI for cyber defence.

5. Static anchors & PYQ frame

  • CERT-In = nodal, IT Act s.70B; NCIIPC = s.70A (under NTRO); FIR with state police; cyber audits mandatory for big/critical entities.
